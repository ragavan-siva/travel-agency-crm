# Travel Agency CRM

Initial MVP for a small travel agency.

## Stack
- Next.js
- TypeScript
- Supabase
- Vercel

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Copy `.env.local.example` to `.env.local`.
4. Create a Supabase project.
5. Put the Supabase URL and anon key in `.env.local`.
6. Run `supabase/schema.sql` in the Supabase SQL Editor.
7. Run `npm run dev`.
8. Open http://localhost:3000.
